# Headphones Landing Page

This project is a fully responsive landing page built from scratch using HTML and CSS, based on a design provided in Figma.

## Features
- Hero/header section
- What we do section
- Our results section
- Contact form
- Footer
- Responsive design for screens ≤ 480px
- Pure CSS icons and animations

## Constraints
- No external CSS frameworks used
- No JavaScript (except task 8)
